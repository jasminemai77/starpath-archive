# Astral data notes

This catalog contains concise factual astronomy descriptions and separate,
non-predictive cultural symbolism. The four supported `type` values are `star`,
`cluster`, `nebula`, and `galaxy`.

Astronomy descriptions are cross-checked against NASA Science's public
overviews of [galaxies](https://science.nasa.gov/universe/galaxies/),
[nebulae](https://science.nasa.gov/mission/hubble/science/universe-uncovered/hubble-nebulae/),
[star clusters](https://science.nasa.gov/mission/hubble/science/universe-uncovered/hubble-star-clusters/),
and the [Hubble Messier Catalog](https://science.nasa.gov/mission/hubble/science/explore-the-night-sky/hubble-messier-catalog/).

`symbolism` is cultural and literary context only; it does not make personal,
financial, or future claims.
