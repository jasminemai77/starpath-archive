# Tarot data notes

The card names, suit order, court ranks, elemental correspondences, and concise
upright/reversed reference meanings are curated as Rider–Waite–Smith-aligned
reference data. They are cultural reference material, not predictions or
personal guidance.

Each card separates:

- `upright_meaning` and `reversed_meaning`: traditional reference cues;
- `keywords` and `symbolism`: symbolic indexing metadata;
- `literary_material`: optional neutral imagery for a future Native Agent to
  present in its own style.

Reference structure: the Rider–Waite tarot's 78-card, 22-major/56-minor layout
and four 14-card suits. See the project README for public reference links.
