# Dark Cosmic Archive — Major Arcana generation template

Use this template for a single future candidate only. Do not use it to replace
an approved `major/` asset. Use `reference/the_star_approved_v1.png` as a style
reference, not a content reference.

```text
Create a premium tarot card for the Starpath Archive "Dark Cosmic Archive" deck.

The card must visually belong to the frozen v1.0 five-card baseline. Use ancient
tarot + cosmic starfield + mysterious archival astronomy. Keep deep space blue,
low-saturation nebula purple, restrained antique gold, ivory typography, subtle
celestial chart ornaments, refined painterly tarot illustration, and a 2:3
vertical collectible-card composition.

Keep consistent: antique-gold double-line border thickness; reduced corner
ornament; top Roman-numeral zone; uppercase English title zone; Chinese title
zone; fixed title tracking; fixed bottom whitespace; one clear focal light;
quiet antique-gold illumination; archival visual density.

CARD-SPECIFIC CONTENT:
- Number: [ROMAN NUMERAL]
- English name: [ENGLISH NAME]
- Chinese name: [CHINESE NAME]
- Traditional core symbols: [SYMBOLS]
- Subject and setting: [SCENE]
- Distinct lighting/story: [LIGHTING]

Text (verbatim): top "[ROMAN NUMERAL]". Bottom first line "[ENGLISH NAME]".
Bottom second line "[CHINESE NAME]". No other text.

Avoid: low quality, blurry, messy layout, unreadable text, extra text,
incorrect tarot title, incorrect Roman numeral, duplicated limbs, bad anatomy,
oversaturated, anime, cartoon, cyberpunk neon, sci-fi HUD, modern UI, game
interface, cheap fantasy, generic poster, photorealistic portrait,
overdecorated frame, random symbols, horror gore, blood, watermark, logo.
```

Before a candidate can be promoted, compare it with all five v1.0 baseline
cards for color, frame, typography, spacing, art style, illumination, symbolic
accuracy, individual identity, archive identity, and scale readiness. Save its
prompt, negative prompt, reference, timestamp, model/seed if exposed, and
resolution in that candidate's `metadata.md`.
